> *Habilidades sobem com uso real — não com intenção.*

---

## 🧠 COMO FUNCIONA

- Skills sobem completando quests relacionadas ao domínio
- Cada nível dá um **XP multiplier permanente** naquele domínio
- Max: Level 5 por skill
- Desbloquear skill nova = 1 Focus Token

| Level | XP Multiplier |
|---|---|
| 1 | Base (sem bônus) |
| 2 | +10% XP neste domínio |
| 3 | +25% XP neste domínio |
| 4 | +50% XP neste domínio |
| 5 | +100% XP neste domínio + Badge especial |
